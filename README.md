# ROCardPicker 發行檔（僅二進位與技能資料）

此為 **公開** 倉庫，只存放 [RO倖存者選卡輔助](https://github.com/Vic1228/ro-card-picker) 的 Windows 發行包與技能資料包，**不含原始碼**。

原始碼在私人倉庫 `Vic1228/ro-card-picker`。程式檢查更新時只會讀這個公開庫的 GitHub Releases，**不需要登入，也不會內建任何 token**。

## 下載

請到 [Releases](https://github.com/Vic1228/ro-card-picker-releases/releases/latest) 下載：

- `ROCardPicker-windows.zip`：解壓後執行 `ROCardPicker/ROCardPicker.exe`
- `data-pack.zip`：技能清單與圖示（程式啟動時會自動熱更新，通常不必手動下載）

最新清單也會放在倉庫根目錄的 [`latest.json`](./latest.json)。

# ROCardPicker v1.6.1

- **修正：遊戲不在前景時，放逐／專注／重抽不該把重試次數用完再改按數字鍵。** 若本程式視窗跑到前景（或你暫時切走），已決定的放逐、專注、重抽整組、單一重抽會一直等到遊戲回到前景再做，等待期間不會改用一般規則選卡；日誌只寫一次，不會洗版。回到前景後先執行該動作，再重新判斷。
- 「不在前景」不計入重試次數。只有「點擊已送出但畫面沒變」或「點擊沒有成功送出」（例如 SendInput 被擋）才算重試（仍是隔 1.5 秒、最多 3 次）。
- 遊戲的「我很強，自動選」勾選／確認同樣：不在前景時維持等待、不解除擋選卡、不計失敗次數。
- 半自動進下一場（v1.6.0）若遊戲不在前景，仍立刻停下並放開按鍵（語意不變）。

- **「請確認你在螢幕前」更明顯的提醒**：遊戲的真人確認視窗（或遠征中的紅色「請先回到城鎮完成確認」提示）出現時，連續警告音＋紅色通知＋閃工作列＋視窗內紅色橫幅。**只提醒，程式絕不碰驗證題。**

- 主城／關卡視窗／難度視窗辨識：字串取自遊戲公開檔（data/stages.json），用中文字型模板比對（以字距推算字級，小字也準）；4 種解析度／DPI／介面縮放的測試畫面全部正確。
- 保留 v1.5.0 以前的所有行為；回城提醒每 1.5 秒最多看一次畫面（平常 2–3 ms），不影響選卡反應速度。

# ROCardPicker v1.5.0

- **卡片中文文字辨識（速度優先）**：只在選卡畫面出現、規則用得到時才讀字。字串全部取自遊戲公開檔，用中文字型模板比對；比不到才退回 Windows 內建 OCR（需要「中文（繁體）」語言包，沒有就只用模板，日誌會提示）。每張卡約 3–5 ms；閒置檢查與「出現→按鍵」延遲不變。
- **升級項目排序**：技能決勝條件新增「升級項目」，可自己排「數量／目標／傷害／急速／範圍…」的先後。
- **普通攻擊可選**：「攻擊：法杖」等 19 種普攻可放進優先／排除／放逐／專注，用名稱文字辨識。普攻神格與圖示分不出的技能神格也改用文字辨識。
- **遊戲「我很強，自動選」自動勾選**（預設關閉）：條件可選角色等級達到 Lv N、技能欄滿、寶箱道具欄滿（可複選）；系統層級擬人化點擊、前景確認、確認框消失才算成功；每局只勾一次、不取消；勾好後本程式該局停止選卡。
- **都不符合時：動作順序鏈**：技能、寶箱各自排「重抽整組 → 單一重抽 → 放逐 → 等待」並可設每種保留幾次；依按鈕上的剩餘次數徽章判斷。舊的「主要動作＋備援」自動遷移。
- 保留 v1.3.1、v1.3.2、v1.4.0 的所有行為。

# ROCardPicker v1.4.0

- **放逐清單／專注清單**（技能、寶箱各自一份，存在設定檔裡）：清單上的卡出現時，先按那張卡下方的「放逐」（本局不再出現、立刻換卡，換完重新判斷）或「專注」（本局之後更常出現），再用數字鍵選卡。多張要放逐時照清單順序、同順位取最左。按鈕找不到、灰掉或遊戲不在前景就不點，日誌寫原因。
- **單人遠征自動 2 倍速**（一般設定，預設關閉）：看到計時器旁的「1x」就按一次 V，並確認變成 2x；每場最多一次，不會連按。
- **技能神格拆開**：寶箱可以指定「某個技能的神格」放進優先／排除／放逐／專注，可依職業篩選、可搜尋。分不出是哪個技能神格時不亂選（等手動或照「都不符合時」）。普攻神格沒有圖示，認不出來。
- 保留 v1.3.1 的寶箱「三張都不在清單 → 照都不符合時」行為與 v1.2.3 的加速。

# ROCardPicker v1.3.2

- **修正：寶箱三張都不符合、決定要重抽，但滑鼠完全沒動，日誌一直刷「同一組卡片已處理過」**。原因有三：①很多人這局只有每張卡下方的「重抽／專注／放逐」，沒有上方的「重抽整組」，程式找不到整組按鈕就放棄；②放棄的原因只印一次，馬上被後面每個監看週期的「已處理過」淹沒；③以前一失敗就把這組標成「已處理」，之後不再重試。
- **新增「都不符合時」選項（技能、寶箱共用）**：等待手動／重抽整組／**單一重抽**（每張卡下方的「重抽」）／放逐；可選「主要動作做不到時（沒按鈕或次數用完）」的備援動作；單一重抽／放逐可選動最左邊、稀有度最低、或依序換張。
- **點擊失敗會重試、有上限**：只有點擊真的送出才算處理過；找不到按鈕、按鈕灰（次數用完）、遊戲不在前景、游標到不了目標、SendInput 被擋（常見：遊戲瀏覽器以系統管理員執行而本程式不是）都會寫明確原因，隔 1.5 秒重試，最多 3 次，之後改等手動。點擊送出後畫面沒變也會寫「點擊後畫面未變化」並有限重試。
- 日誌相同訊息合併（「…（已重複 N 次）」），不再每個週期刷屏。
- **新增「測試點擊（診斷）」**（或 `--diagnose-click`）：只把游標移到偵測到的按鈕上停住（不按下），把截圖、偵測框、座標、權限／DPI 資訊存到 `%LOCALAPPDATA%\ROCardPicker\diag\`（含 zip），方便回報。

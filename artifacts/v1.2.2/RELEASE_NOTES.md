# ROCardPicker v1.2.2

- 修正：安裝路徑含中文或空白時，按程式內「更新」只會跳出 cmd 小黑窗（「系統找不到指定的路徑。」）且更新不會完成。原因是舊更新器把路徑寫進 UTF-8 的 .bat，cmd 卻用系統編碼（繁中 Windows 為 cp950）讀取，路徑變成亂碼。
- 現改由解壓出的新版 exe 以 Unicode 參數執行 `--apply-update`：等候舊行程結束、覆寫安裝目錄、再重開；失敗會跳出可讀錯誤並寫入更新紀錄，不會留下卡住的 cmd 視窗。使用者預設檔仍在 %LOCALAPPDATA%，不會被覆寫。
- 注意：v1.2.1 與更早的已安裝版本仍內建舊更新器，這次請手動下載本發行包覆蓋安裝資料夾；之後即可在程式內正常更新。

# ROCardPicker v1.2.1

- 修正：在真實遊戲 CSS（技能與寶箱畫面）下，v1.1.1 的按鈕偵測會漏掉每張卡的「重抽／放逐」和「重抽整組」。次數徽章（右上藍圓數字）與白色／淺色寶箱卡會讓舊的色塊＋整顆按鈕模板對不到。
- 現改為只在卡片下方與 #pk-bar 的先驗區域搜尋，並用多尺度文字標籤比對（徽章不進入模板）；找不到或信心不足時仍然不點。
- 加入技能／寶箱官方 CSS 渲染回歸測試（不同稀有度卡色、次數徽章、停用半透明、視窗大小與縮放）。

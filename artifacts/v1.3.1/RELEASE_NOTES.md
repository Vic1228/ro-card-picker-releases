# ROCardPicker v1.3.1

- **修正：寶箱三張都不在偏好清單，卻不會按重抽**。原因：v1.2 的寶箱預設是「不在清單的裝備也可以選」，三張都不在清單時程式還是會硬挑一張，所以永遠走不到「都不符合時：重抽」。現在舊設定（含已經遷移到 v1.3.0 的「v1.2 內建建議」「…（寶箱）」設定檔）會改成「不在清單的不選」，三張都不符合就照「都不符合時」的設定重抽整組／放逐／等待。手動建立、明確選「也可以選」的設定檔不會被改。
- 重抽後的新一組以卡片內容判斷，會重新判斷；按了重抽畫面仍是同一組時最多再試 3 次，之後改等手動（不會無限連點）。
- 狀態列和日誌會寫出為什麼等待／重抽／放逐（例如「寶箱 3 張都不符合（…不在偏好清單），依『都不符合時』設定：重抽整組」）；找不到重抽按鈕或按鈕灰掉（次數用完）時會明講。
- 空白清單的行為不變：「不選」＝都不符合，「也可以選」＝靠稀有度／最新！挑；說明文字更清楚。

# ROCardPicker v1.2.3

- 大幅加快選卡反應：以前閒置時每次檢查要數秒到數十秒（掃整個畫面比對全部技能圖示），所以你把秒數調再低也選得慢。現在閒置每次約 0.01 秒，看到選卡畫面後約 0.05～0.1 秒辨識完。
- 你設定的「按鍵前隨機等待」現在真的是主要等待時間：設 0／0 時從畫面出現到按鍵約 0.2～0.3 秒（以前約 4 秒）。
- 「監看間隔」設定生效（預設 0.15 秒，視窗內可調）。以前這個欄位沒有作用，固定 0.4 秒。
- 辨識結果與舊版一致（207 張測試圖逐張比對）；找不到或不確定仍然不按。
- 遊戲不在前景時不再截圖與辨識；按鍵前會再確認一次前景。
- 「測試截圖」維持完整掃描；技能共用同一張圖示時，會優先認成你排進優先層的那一個。
